# Выдача доступа (grant.py)

Рабочая папка: `/Users/chilikin-a/Documents/claude`. Все команды запускать из неё.
Интерпретатор: системный `python3` (3.12). Обратный раннер к `deactivate.py`: те же креды, те же плагины, тот же persistent-профиль браузера на сервис.

## Область

Только онбординг-шаблон с заголовком `Доступ к <Сервис> - <ФИ>`. Форма «Заявка на лицензию/доступ» намеренно **не** обрабатывается: это закупки и партнёрские запросы, их делают руками.

Invite реализован в трёх плагинах:

| Сервис в Asana | Плагин | Режим | Референс |
|---|---|---|---|
| Figma | `svc_figma.invite` | браузер + TOTP | [references/figma.md](references/figma.md) |
| Adobe Creative Cloud (RedBark), Adobe | `svc_adobe.invite` | UMAPI, без браузера | [references/adobe.md](references/adobe.md) |
| ChatGPT, ChatGPT Team | `svc_chatgpt.invite` | браузер, session-auth | [references/chatgpt.md](references/chatgpt.md) |

Остальные сервисы дают статус `missing-invite` в плане и пропускаются. Как добавить `invite()`: [references/adding-invite.md](references/adding-invite.md).

## Что делает раннер

1. Берёт задачи с due-date `--date` (текст «Доступ к», открытые, на текущем пользователе) или одну задачу по `--task <gid>`.
2. Парсит из **notes**: `Сервис:` (приоритет над заголовком), `Корпоративная почта:` или `email сотрудника:` (цель), `Роль:` или лист `Путь к объекту: … -> <Product>` (роль). Заглушка «Другое» игнорируется, роль по умолчанию `full`.
3. Печатает предупреждения `!` на каждую задачу: расхождение сервиса между notes и заголовком, лишние email в теле, заглушка в роли. **Всегда пересказывай их пользователю**, они ловили выдачу не тому аккаунту.
4. Guard по комментариям: задача с заголовком автоматизации помечается `already-processed`.
5. Запускает Playwright под `playwright-stealth` (Cloudflare Turnstile на некоторых логинах), вызывает `invite(context, creds, target, role)`.
6. Скриншот в `screenshots/<date>/grant/`, комментарий-заголовок в задачу, закрытие задачи при успехе.

## Порядок работы

1. **Сначала dry-run**, показать план с ролями и предупреждениями.
   ```bash
   python3 grant.py --date 2026-09-23 --dry-run
   ```
   Одна задача:
   ```bash
   python3 grant.py --task 1217366391048351 --dry-run
   ```
2. Если роль в плане не совпадает с тем, что просят в задаче, остановись и уточни. Для Adobe роль определяет, какая лицензия будет выдана.
3. Боевой запуск, браузер по умолчанию видимый:
   ```bash
   python3 grant.py --task 1217366391048351 --yes
   ```
4. Прочитай `=== summary ===`, отчитайся по строкам. Если есть `asana-comment-error` с `tasks:write`, комментарий ушёл, а задачу нужно закрыть руками.

## Флаги

| Флаг | Смысл |
|---|---|
| `--date YYYY-MM-DD` / `--task <gid>` | ровно один из двух |
| `--service NAME` | фильтр по сервису, подстрока, повторяемый |
| `--dry-run` | только план |
| `--yes` | без вопроса (обязателен из Claude, stdin не TTY) |
| `--headless` | без окна |
| `--no-comment` | не писать в Asana вообще |
| `--no-complete` | комментировать, но не закрывать задачу |
| `--force` | перезапуск задач с комментарием автоматизации, только по явной просьбе |
| `--screenshot-dir` | по умолчанию `screenshots` |

## Статусы invite

| Статус | Значит | Комментарий / закрытие |
|---|---|---|
| `invited`, `invited (…)` | приглашение отправлено / группы добавлены | заголовок сервиса, задача закрывается |
| `already-invited`, `already-member` | доступ уже был | «Пользователь уже имеет доступ к …», закрывается |
| `skipped: <причина>` | плагин отказался (например, домен) | «Действий не выполнено», НЕ закрывается |
| `needs-confirmation: …` | нужно решение человека (роль не замаплена) | без комментария, перезапуск после правки |
| `needs-login: …` | сессия протухла (session-auth) | без комментария, `prime_session.py` и перезапуск |
| `failed: …` | ошибка | без комментария |

Статусы `failed`/`needs-*` намеренно не пишутся в Asana: это «перезапусти», а не результат.

## Окружение

Боевые прогоны идут на **Windows-хосте** с Vault и `.venv`. На этом Mac `VAULT_ADDR` пустой, любой запуск падает с `secrets error: VAULT_ADDR is not set`. Не переключай бэкенд секретов ради запуска. На Mac допустимы только правки кода, проверки синтаксиса и `--help`. Подробнее в скилле `deactivate`, раздел «Окружение».

## Правила

- Не запускай боевой прогон без dry-run в этой же сессии.
- Не обрабатывай задачи «Заявка на лицензию/доступ» этим раннером даже по просьбе, объясни, что они вне области.
- Домены партнёров: Figma переписывает `@fluytstudio.net` в `.ff@playrix.com`, ChatGPT наоборот принимает **только** `@fluytstudio.net`. Не «исправляй» адрес в задаче руками, плагин это делает сам.
- Значения секретов не печатать. Проверка ключей: `python3 secrets_provider.py --check`.
